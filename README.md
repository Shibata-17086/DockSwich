# DockSwich

DockSwichは、macOSのDockを簡単に表示・非表示できるメニューバーアプリケーションです。

## 主な機能・仕様

- メニューバーからワンクリックでDockの表示・非表示を切り替え
- 現在のDockの状態を自動検出し、UIに反映
- キーボードショートカットでDockの表示・非表示をトグル（任意の複合キーを登録可能）
- システム起動時に現在のDock設定を自動適用（オプション）
- アプリの自動起動（ログイン時に起動）設定
- Appleらしいシンプルで統一感のあるUIデザイン
- 設定はすべてアプリ内で完結し、UserDefaultsに保存

## UI構成

- **Dock状態表示**: Dockが「表示中」か「非表示」かをラベルとアイコンで表示
- **Dock切り替えボタン**: 現在の状態に応じて「Dockを表示する」「Dockを非表示にする」ボタンが切り替わる
- **システム設定セクション**:
    - 「現在のDock設定をシステム起動時に適用」: チェックを入れると、次回起動時にDockの状態を自動で復元
    - 「ログイン時に自動的に起動」: チェックを入れると、macOSログイン時にDockSwichが自動起動
- **ショートカットキー設定セクション**:
    - 「ショートカットを記録」ボタンで任意の複合キー（例: ⌘+⌥+Dなど）を登録可能
    - 登録済みショートカットはラベルで表示
    - 「ショートカットをクリア」ボタンで登録解除
    - ショートカットキーの変更時はアプリの再起動が必要（アラートで案内）
- **メニューバーアイコン**: DockSwichのアイコンからもDockの表示・非表示を切り替え可能

## システム要件

- macOS 11.0以降

## インストール方法

1. リリースページからDockSwich.appをダウンロード
2. アプリケーションフォルダに移動
3. アプリを起動

## 使い方

1. アプリを起動すると、メニューバーにDockSwichアイコンが表示されます
2. アイコンをクリック、またはショートカットキーでDockの表示・非表示を切り替え
3. 設定画面から各種オプションを変更可能
4. メニューから「終了」を選択すると、アプリケーションを終了できます

## 注意事項

- Dockの表示/非表示切り替えはmacOSのシステム設定を直接変更します
- ショートカットキーの変更はアプリの再起動後に有効になります
- Dockの再起動時、一部アプリのウィンドウ位置が変わる場合があります
- システム権限やセキュリティ設定によっては一部機能が動作しない場合があります

## 開発情報

このアプリケーションはSwiftUIを使用して開発されています。

- UI: Appleらしいシンプルなデザインを意識
- 設定保存: UserDefaults
- グローバルホットキー: Carbon APIを利用
- Dock制御: シェルコマンドで`defaults`と`killall Dock`を使用
