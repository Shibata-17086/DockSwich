# DockSwich

DockSwichは、macOSのDockを簡単に表示・非表示できるメニューバーアプリケーションです。

## 機能

- メニューバーからワンクリックでDockの表示・非表示を切り替え
- 現在のDockの状態を自動検出
- キーボードショートカット対応

## システム要件

- macOS 11.0以降

## インストール方法

1. リリースページからDockSwich.appをダウンロード
2. アプリケーションフォルダに移動
3. アプリを起動

## 使い方

1. アプリを起動すると、メニューバーにDockアイコンが表示されます
2. アイコンをクリックすると、Dockの表示・非表示が切り替わります
3. メニューから「終了」を選択すると、アプリケーションを終了できます

## 開発情報

このアプリケーションはSwiftUIを使用して開発されています。
